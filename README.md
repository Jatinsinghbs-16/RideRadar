# RideRadar Animated Experience

This package updates the RideRadar comparison interface with a brief animated welcome screen, page/hero entrance motion, animated ride cards, and responsive hover/press/focus states for clickable controls.

## Publish on GitHub Pages
1. Extract this ZIP.
2. Open your repository and upload/replace `index.html` with the one in this folder (keep your existing README if preferred).
3. Commit directly to `main`.
4. Wait for GitHub Pages to rebuild, then hard refresh with Ctrl+F5.

## Important data limitation
The interface does not have authorized live fare/ETA feeds for Uber, Ola, Rapido, or Namma Yatri. It does not fabricate prices. Provider buttons open provider services so the user can check and confirm a ride there. Live comparison and verified fastest/safest rankings require authorized data integrations.
